# 기능 상태와 확인 근거

기준일: 2026-10-07. 본인이 제공한 미완성 목록과 설명을 기준으로 공개 코드를 정적으로 대조했습니다. 외부 API 호출·실서비스 재현·사용자 테스트는 수행하지 않았습니다.

**미완성은 코드가 전혀 없다는 뜻이 아닙니다.** 개발 중 함수·UI가 존재해도, 프로젝트 기한 내 통합·검증을 마치지 못한 기능은 완료로 표시하지 않습니다.

| 기능 | 상태 | 코드에서 확인한 범위 / 제한 |
|---|---|---|
| 선택지 분기 | 제안 및 구현 진행, 기한 내 미완성 | `branch_story`, 분기 URL, `chooseBranch` UI 존재. 완료·정상 동작의 증거가 아님 |
| BGM 삽입 및 제어 | 미완성 | `generate_bgm`, 정적 `bgm` audio 요소 존재. 장면별 통합 완료는 확인하지 못함 |
| BGM 음량·ON/OFF | 미구현 | 페이지 TTS 재생 제어와는 다른 요구사항 |
| TTS 목소리 선택 | 미구현 | 음성 합성 함수는 있으나 사용자가 목소리를 고르는 완료 기능은 아님 |
| 퀴즈·미니게임 | 미구현 | 해당 화면·흐름의 완성 근거 없음 |
| 부모·자녀 대화 카드 | 미완성 | `generate_discussion_cards`와 카드 표시 UI 존재. 팀의 미완성 목록을 완료로 뒤집지 않음 |
| 콘텐츠 필터링 | 부분 구현 / 통합 미완성 | 이미지 API의 `CONTENT_FILTERED` 처리 존재. 텍스트 생성 전후 Moderation 및 한국어 분류기 통합 코드는 확인되지 않음 |
| 이미지 일관성 | 부분 구현 | seed 공유와 참조 이미지 관련 처리 시도 존재. 일관된 출력의 검증 결과는 아님 |

## 대조한 파일

- [stories/views.py](../stories/views.py): 생성, 분기, TTS, BGM, 카드 함수와 이미지 필터 응답 처리
- [stories/urls.py](../stories/urls.py): 생성·분기 등 라우팅
- [templates/1start.html](../templates/1start.html): 입력 화면
- [templates/2story.html](../templates/2story.html): 페이지·선택지·오디오·카드 UI
- [stories/tests.py](../stories/tests.py): 테스트 작성 자리만 있으며, 위 기능의 통합 검증 근거로 사용할 수 없음

## 기여 표현 정정

선택지 분기는 본인이 제안했고 구현 작업에 참여했지만, 기한 문제로 최종 완성하지 못했습니다. 음성 클로닝·API 탐색 및 연결·필터링 관련 담당 이력과, 각 기능의 완성 여부를 혼동하지 않습니다.

이번 문서 정정은 코드를 삭제하거나 기능을 완성한 작업이 아닙니다. 과거 표현은 Git 이력에 남으며, 현재 상태는 이 문서와 README가 기준입니다.
